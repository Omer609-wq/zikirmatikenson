## Yeni arayüz metni

1. `locales/en.json` ve `locales/tr.json` içine aynı anahtarı ekle (ör. `settings.foo`).
2. `index.html` veya JS içinde `data-i18n="settings.foo"` veya `t('settings.foo')`.
3. Aynı anahtarı **diğer 6 locale** dosyasına çevir: `ar`, `id`, `ms`, `fr`, `bn`, `ur`.
4. Doğrula: `npm run i18n:verify` (veya `npm test`).

Eksik anahtar → `i18n.js` içinde `t()` **Türkçe fallback** gösterir (`tr.json`).

Locale'e özel ek anahtar (nadir): `scripts/verify-locale-keys.cjs` içindeki `ALLOWED_EXTRA_KEYS` (ör. `ar` → `quran.searchArHit`).

## Yeni kütüphane maddesi

1. `data/library/tr.json` sonuna nesne ekle (`id`, `category`, `name`, `meaning`, `context`, `source`, `target`, `keywords`).
2. Çeviri için `data/library/id.json` içine **aynı `id`** ile sadece çevrilen alanları yaz.
3. `app.js` içine dizi **ekleme** — gerekirse `node scripts/extract-library-to-json.cjs` ile `app.js`'den export (geçici).

## Editöryal kurallar (kütüphane)

- `meaning`: doğru, sade meal
- `context`: muteber özet; kesin vaat iddiasından kaçın
- `source`: mümkünse kitap/bab
- `target`: rivayete uygun; değilse düşük tut ve `context`'te açıkla
- `keywords`: arama; hüküm iddiası değil

## Uzaktan kütüphane düzeltmesi (mağaza güncellemesi olmadan)

`public/library-overrides.json` → jsDelivr CDN → `git push` ile yayına girer. Sadece
**mevcut** maddelerin metni değişir; yeni madde eklenmez (bilinmeyen `id` yok sayılır),
kod/ekran değişikliği yapılamaz. Kod: `library-overrides.js` (indirme) +
`lib/library-overrides.js` (şema/doğrulama) + `i18n.js` (birleştirme).

```json
{
  "items": {
    "lib_2": {
      "tr": { "meaning": "Yeni TR meal", "context": "Yeni fazilet", "source": "Buhari, ..." },
      "en": { "meaning": "New EN meaning", "context": "Dua bağlamı (TR dışı ortak)" },
      "ar": { "name": "..." }, "bn": { "name": "..." }, "ur": { "name": "..." },
      "prev": { "meaning": ["yerine geçtiği eski metin"] }
    }
  }
}
```

Katmanlar `data/library/*.json` ile aynı model: `tr` kanon (`arabic`, `target`, `source`
dahil), `en` TR dışı ortak meal/bağlam, `ar`/`bn`/`ur` yalnızca okunuş adı.
Alanlar: `name`, `meaning`, `context`, `source`, `keywords`, `arabic`, `target`,
`category`. Boş metin = değişiklik yok.

**`prev` neden zorunlu.** Kullanıcının klasöründeki kayıt metnin bir kopyasını saklar;
`app.js` yalnızca "bilinen" metinleri günceller, elle düzenlenmiş metne dokunmaz. Gömülü
JSON'daki metin zaten bilinir, ilk düzeltme sorunsuz geçer. **İkinci** düzeltmede (v1 → v2)
v1'in metnini `prev` içine yaz; yoksa v1'i almış kullanıcılarda güncelleme durur.
`prev.fazilet` zikir maddesinin TR `context` metni içindir.

Keşfet listesi her zaman en güncel metni gösterir — `prev` yalnızca kullanıcının **eklediği**
kaydı ilgilendirir.

**Geri alma:** katmanları boşalt, yanlış metni `prev` içinde bırak. CDN'den geçerli ama
boş `items` gelirse tüm düzeltmeler geri alınır (paketli kopya bunu yapamaz — ağ yokken
önbelleği silmemesi için).

Akış: açılışta önbellek anında uygulanır → CDN tazelenir → değiştiyse kayıtlı zikirler
yeniden senkronlanır. Acil purge:
`https://purge.jsdelivr.net/gh/Omer609-wq/zikirmatikenson@main/public/library-overrides.json`
